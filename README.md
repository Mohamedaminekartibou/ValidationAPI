# ValidationAPI

## Descripció
Llibreria pròpia en Java creada per centralitzar les validacions de dades de l'aplicació GestioVideojocs.

## Funcionalitats
- Comprovar que un nom comença amb majúscula.
- Comprovar si un text està buit.

## Tecnologies
- Java
- Maven

## Ús
La llibreria es fa servir des del projecte GestioVideojocs per validar les dades introduïdes pels usuaris.
